# 🏥 MedApp

MedApp is a modern Hospital Management System designed to streamline healthcare operations by providing an intuitive platform for managing patients, appointments, doctors, and hospital records. Built with Next.js, the application delivers a fast, responsive, and user-friendly experience for healthcare providers.

---

## 🚀 Features

- 👤 Secure User Authentication
- 🩺 Patient Registration & Management
- 👨‍⚕️ Doctor Management
- 📅 Appointment Scheduling
- 📋 Patient Medical Records
- 💊 Prescription Management
- 📊 Admin Dashboard
- 🔍 Search & Filter Functionality
- 📱 Fully Responsive Design
- ⚡ Fast Performance with Next.js

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/anwar730/med-app-frontend.git
```

Navigate to the project directory

```bash
cd med-app-fronten
```

Install dependencies

```bash
npm install
```

Create a `.env` file and configure your environment variables.

Example:

```env
DATABASE_URL=
NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=
CLERK_SECRET_KEY=
```

Run the development server

```bash
npm run dev
```

Open your browser and visit

```
http://localhost:3000
```

## 🎯 Objectives

The primary goal of MedApp is to digitize hospital operations by:

- Improving patient record management
- Reducing paperwork
- Simplifying appointment booking
- Enhancing communication between healthcare staff
- Increasing operational efficiency

---

## 🔐 User Roles

### Admin
- Manage doctors
- Manage patients
- View reports
- Manage appointments

### Doctor
- View assigned patients
- Update medical records
- Write prescriptions
- Manage appointments

### Patient
- Book appointments
- View prescriptions
- Access medical history
- Update profile
